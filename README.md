# Sabar.in

"Emosi di hati aja, professional kudu tetep jalan"

Sabar.in adalah aplikasi web yang ngebantu kamu waktu lagi emosi sama kerjaan, rekan kerja, atau klien. Ketik aja uneg-uneg kamu yang paling kasar atau jujur, dan AI kita bakal ubah kata-kata itu jadi bahasa korporat yang super rapi, sopan, dan profesional. 

Langsung cobain aplikasinya di sini:
👉 **[https://sabarin-app.vercel.app/](https://sabarin-app.vercel.app/)**

### Kenapa pakai Sabar.in?
Kadang kita pengen banget balas email dengan kalimat pedas, tapi sadar kalau itu bisa bahayain karir. Sabar.in ngasih jalan tengah: kamu tetap bisa meluapkan emosi di form ketikan, tapi yang keluar dan kamu kirim ke orangnya adalah versi yang elegan dan aman buat urusan kantor.

Kamu bisa milih 3 gaya bahasa:
- **Professional**: Fokus ke solusi dan ketenangan.
- **Savage-but-Polite**: Sopan tapi nyindir halus (passive-aggressive).
- **Direct**: Langsung ke intinya tanpa basa-basi, tapi tetap formal.

Setiap hasil terjemahan juga bakal dikasih skor, seberapa "Savage" kalimat aslimu dan seberapa "Professional" hasil perbaikannya.

### Buat Developer
Aplikasi ini dibangun pakai React, Tailwind CSS, dan Google Gemini AI. Kalau kamu pengen ngulik atau jalanin di komputer sendiri:
1. Clone repo ini
2. Run `npm install`
3. Bikin file `.env.local` dan masukin `GEMINI_API_KEY=key_kamu_di_sini`
4. Run `npm run dev`

Tapi kalau cuma mau pakai, langsung aja buka [link Vercel di atas](https://sabarin-app.vercel.app/). Nggak perlu repot install apa-apa!
